## 启动与登录流程

```text
打开小程序
  → 直接进入「总览」tab；未登录时明确提示总览按账号区服 / 同盟读取
  → 进入「我的」：未登录直接进入登录页，可点「先逛逛」返回
  → 用户主动点击“微信登录”
      → 云函数识别微信身份（无自建 Token）
      → 角色未初始化：进入角色初始化
      → 角色已初始化：进入个人中心
  → 微信头像昵称仍可选择“之后完善”，不是登录前置条件
```

启动不调用 `bootstrap`，不弹授权，不自动进入登录页，也不申请手机号权限；总览等账号数据页未登录时不伪造内容。
`pages/index` 登录页仍是普通非 tab 页面，不作为启动页；进入「我的」且未登录时直接打开它。
微信平台不允许小程序静默读取真实头像昵称，因此头像昵称只能由用户在需要时主动选择。

## 功能

1. **可信微信身份识别（仅在用户主动登录时）**
   - 云函数从可信上下文 `cloud.getWXContext().OPENID` 获取身份；
   - 首次调用建立平台账号，后续复用同一个账号；
   - 不使用 `wx.login` + 自建 `jscode2session`，不使用自建 Session。
2. **可选微信资料完善**
   - 只有用户主动进入资料页时才提供头像/昵称填写，不做登录前置；
   - 使用官方 `chooseAvatar` 与 `input type="nickname"`；
   - 可稍后完善，不自动打断浏览；
   - 头像最大 500KB，前端压缩、云函数再次校验大小与文件签名。
3. **游戏角色初始化**
   - 游戏昵称：必填、最长 30 字符；
   - 当前总战力：必填、非负整数、最大 `999999999999`；
   - 性别：男/女/保密，必须主动选择，无默认值；
   - 角色资料与 `profileInitialized` 标记通过云数据库事务同时写入。
4. **个人中心**
   - 进入「我的」时未登录直接进入登录页，可点「先逛逛」返回总览；
   - 微信头像、微信昵称（可选完善）；
   - 基础信息：游戏昵称、性别、所属区服、所属同盟；
   - 核心属性：8 项百分比 + 出征兵力上限，可进入独立编辑页修改；
   - 微信资料在设置页编辑，游戏资料在基础信息 / 核心属性的「编辑 →」中分块编辑；
   - 全部读取自云函数，不做本地资料缓存渲染。
5. **再次登录与恢复**
   - 进入「我的」时未登录直接进入登录页；登录页可「先逛逛」返回总览；
   - 登录必须由用户主动点击，不做启动拦截；
   - 清除本地缓存后仍能识别回原账号；
   - 云函数不接受前端传入的用户 ID，不返回 OpenID、UnionID 或头像 fileID；
   - 不调用 `getPhoneNumber`，不申请手机号权限。

## 云开发部署

1. 在微信开发者工具中打开本项目，确认已登录当前 AppID 且有云开发权限。
2. 右键 `cloudfunctions/sanbingAccount`，选择“上传并部署：云端安装依赖”。
3. 云数据库集合：`sanbing_users`、`sanbing_game_profiles`。
4. 云存储头像目录：`avatars/<publicId>/...`。
5. 直接编译运行。首次身份由 `wx.cloud` 自动完成，不需要配置服务器域名或 AppSecret。

云函数当前运行时为 `Nodejs16.13`，超时 3 秒。正式运营前建议在云开发控制台把超时调到 `20s`，并确认“微信体验版”套餐的额度和续费情况。

## 安全与配置注意

- 全业务访问经过云函数；客户端不直接向业务集合写入数据。
- 云函数校验微信上下文、字段、组织状态、重复初始化和头像实际文件签名。
- 云函数会忽略/覆盖带客户端 `_openid` 的伪造业务文档。
- 上线前建议把两个集合权限设置为 **仅管理员可读写**，避免客户端向集合写入垃圾文档。
- 头像文件保存在云存储，客户端只使用云函数生成的短时签名 URL。
- 不申请手机号权限，不调用 `getPhoneNumber`。
- 仍需在微信公众平台配置用户隐私保护指引（头像、昵称、OpenID 等）。
- 原生头像选择面板本身允许用户从相册选择；微信不提供“只能选择微信头像/只能选择昵称”的强制接口，本项目无法阻止用户手动选择或输入。
- 上线前在真机手动点选一次官方头像选择器，确认微信原生面板与保存链路正常。

## 底部导航

底部固定四个一级入口：

```text
总览 / 拜访 / 同盟 / 我的
```

- **总览**：同盟全员属性汇总，当前空白状态；
- **拜访**：同盟成员列表与个人中心查看，当前空白状态；
- **同盟**：创建 / 加入 / 管理同盟，当前空白状态；
- **我的**：当前个人中心，是唯一已有完整内容的 tab。

底部导航是自定义组件 `custom-tab-bar/`，不是微信原生默认样式；四个 tab 页和登录页顶部使用 `components/nav-bar/` 自定义导航栏，避免微信原生导航栏在切页 / 刷新时闪白色首帧及首页按钮。登录、微信资料、角色初始化属于流程页，不出现底部导航。

个人中心身份行右侧提供「设置 →」，微信资料编辑、账号信息、应用信息和“退出登录”都在独立设置页；退出登录只退出本机状态并回到总览，**不会解除微信身份、不会删除云端档案**。再次进入「我的」时可重新登录。
