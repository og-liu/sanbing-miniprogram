<summary><b>2026-11-13 14:40 · 修复 tab 页空滚动条</b> —— 去掉 100vh 与导航 spacer 的叠加</summary>

<br>

**现象**

总览 / 拜访 / 同盟等内容明显没有超过一屏，却可以上下拖动，出现无意义滚动条。

**原因**

tab 页使用自定义导航栏：`nav-bar` 的 spacer 已经占据顶部高度；页面又继承 `.page { min-height: 100vh }`，实际高度变成“导航高度 + 视口高度”，必然溢出。

**处理**

- `.tab-page` 显式设置 `min-height: 0`；
- 页面高度由内容决定，底部 tabBar 留白保持不变；
- 原生导航的非 tab 页不动，仍由 `100vh` 正常撑满。

**产出**

- 修改：`app.wxss`
- 更新：设计规范 v3.5.4
- 未改页面内容、数据或接口

</details>

<summary><b>2026-11-13 14:00 · 审核驳回整改：先浏览，后登录</b> —— 移除启动登录墙</summary>

<br>

**审核驳回原文**

“小程序打开一进入【首页】页面，未浏览体验功能服务，即要求授权手机号码、头像、昵称进行授权登录，请在用户体验浏览功能服务后，再自行选择授权登录。”

**原因**

上一版将 `pages/index/index` 登录页作为启动首页，首次进入直接停在微信登录封面；登录后又自动进入微信资料页。即使用户没有点选任何头像 / 昵称，审核也会把这套流程视为“未浏览先要求授权”。代码本身没有 `getPhoneNumber`，但“强制登录 / 授权前置”是确实存在的问题。

**整改**

- `app.json` 第一页改为 `pages/overview/overview`，启动直接进入可浏览的总览 tab，不调用 `bootstrap()`；
- `pages/index/index` 从 `app.json` 注销，登录页不再参与路由（文件保留，不再作为入口）；
- 个人中心新增游客态：
  - 未登录时显示说明、`GUEST` 标记、可选「微信登录」和「先去总览看看」；
  - 只有用户主动点击才 `bootstrap()`；
  - 登录成功后按角色初始化状态分流，不再自动进入微信资料页；
- 微信头像 / 昵称改为可选完善，只能从个人中心提示或设置页进入；
- 退出登录后回游客态；注销账户后回总览；
- 不申请手机号权限，不调用 `getPhoneNumber`；
- 总览空状态补充“无需登录即可浏览”。

**影响**

- 原“首次进入停在登录页”的产品要求被审核规则推翻，改为游客优先；
- 云端数据和接口不变，`updateGameProfile` 已部署；
- 单元测试 8/8 通过。

**产出**

- 修改：`app.json`、`pages/profile/*`、`pages/overview/*`、`services/auth.js`、`services/onboarding.js`、`pages/settings/settings.js`
- 更新：README、设计规范 v3.5.0、目录结构说明、云函数接口文档变更记录
- 未上传、未发布；等待重新提交审核

</details>
